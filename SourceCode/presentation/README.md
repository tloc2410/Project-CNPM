# Presentation Layer

Đặt mã giao diện tại đây: HTML, CSS, JavaScript hoặc template của framework đã được nhóm thống nhất.

Trách nhiệm:
- Hiển thị dữ liệu.
- Nhận thao tác và dữ liệu nhập từ người dùng.
- Gửi yêu cầu tới Backend.
- Hiển thị kết quả và thông báo lỗi.

Không đặt quy tắc nghiệp vụ quan trọng hoặc truy vấn SQL trực tiếp trong giao diện.
