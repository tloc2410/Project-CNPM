# Database – Group 12 Car Rental

Thư mục này để nhóm lưu file SQL do các thành viên tự tạo và thống nhất.

- Bạn có thể thêm file `.sql` trực tiếp vào thư mục này.
- Trước khi chia sẻ, hãy chạy thử file bằng MySQL Workbench.
- Khi có thay đổi, đưa file lên GitHub bằng branch và Pull Request để cả nhóm kiểm tra.
- Không đưa mật khẩu, file `.env`, dữ liệu khách hàng thật hoặc thông tin thẻ thanh toán lên GitHub.

GitHub không lưu thư mục rỗng, vì vậy giữ README này để thư mục Database hiển thị trong repository.
